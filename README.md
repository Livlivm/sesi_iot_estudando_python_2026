# Estudando Python

## Descrição

Lista de exercícios de Python resolvidos em aula no SESI SENAI, no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias utilizadas

- Python
- Visual Studio Code (VS Code)

## Para testar

1. Abra a pasta do projeto no VS Code.
2. Abra o terminal.
3. Execute o arquivo desejado utilizando o comando:

```bash
python nome_arquivo.py
```

**Exemplo:**

```bash
python soma.py
```

## Exercícios desenvolvidos

- Soma de dois números inteiros.
- Verificação de número par ou ímpar.
- Exibição dos números de 1 a 100.
- Cálculo da média de três números.
- Conversão de temperatura de Celsius para Fahrenheit.
- Cálculo de fatorial.
- Verificação de ano bissexto.
- Identificação de número positivo, negativo ou zero.
- Comparação de dois números.
- Verificação de maioridade.
- Classificação de triângulos.
